# Branche QA

## Liste des correctifs à valider

- L'application gère les adresses e-mail invalides
- Il n'est pas possible de réserver plus de places que le solde de points disponibles
- Il n'est pas possible de réserver plus de 12 places par competition
- Les places réservées sont déduites du nombre de places disponibles de la competition
- Il n'est pas possible de réserver des places sur une compétition passée
- Les points du club sont décrémentés du nombre de places réservées
- Il n'est pas possible de réserver plus de places que disponible pour chaque competition
- Un tableau listant les clubs et leur nombre de points disponibles est accessible
- Il n'est pas nécessaire de se connecter au site pour accéder à ce tableau
